# Fri3D Camp 2026 Badge

- Status: working on prototype, production run of 700 devices started
- Ref: https://github.com/Fri3dCamp/badge_2026_hw/
- Ref: https://fri3d.be/

This port developed for the Fri3D Camp 2026 Badge, based on the ESP32-S3 microcontroller.

# Hardware info

- Espressif ESP32-S3-WROOM-1-N16R8 (16MB flash + 8MB PSRAM)
- ST7789-based 2-inch IPS LCD at 240x320 with I2C capacitive touch input
- analog joystick (X and Y axis)
- buttons: X, Y, A, B, MENU, START (and reset)
- microSD card reader
- 6-axis IMU
- Piezoelectric Buzzer
- Audio DAC with headset connector
- 5 multicolor LEDs (WS2812C)
- IR receiver
- Debug LED
- battery charger
- battery (2000 mAh)
- USB-C connector
- Stemma QT connector
- Expansion Connector for "Communicator Add-on" which has I2S digital microphone, QUERTY keyboard, and additional audio DAC with speaker
